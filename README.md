# NoAdmin Soft

Легковесный скрипт автоматизации для Windows, который позволяет устанавливать популярный софт (**Discord**, **Steam** и др.) в обход ограничений учетной записи — **полностью без прав администратора (UAC)**. 

Проект построен на базе портативного пакетного менеджера `Scoop`, который изолирует программы в домашней директории пользователя и не требует системных привилегий для работы.

## 🚀 Быстрый старт

Просто откройте обычный **PowerShell** (не от имени администратора) и выполните одну команду:

```powershell
irm "https://raw.githubusercontent.com/WackFlow/NoAdmin-Soft/refs/heads/main/install.ps1" | iex
```

---

## 🛠️ Как это работает

Скрипт полностью автоматизирует рутинную настройку среды:
1. **Политики безопасности:** Временно разрешает запуск удаленных скриптов в текущей сессии пользователя (`RemoteSigned`).
2. **Менеджер пакетов:** Скачивает и разворачивает ядро `Scoop` прямо в профиль пользователя (`%USERPROFILE%\scoop`).
3. **Окружение Git:** Устанавливает портативную версию Git для последующей синхронизации официальных баз софта.
4. **Подключение репозиториев:** Подключает расширенные базы программ `extras` и `games`.
5. **Установка софта:** Скачивает, распаковывает и настраивает **Discord** и **Steam** без единого запроса прав администратора.

---

## 📂 Структура репозитория

Вы можете использовать любую удобную для вас версию скрипта из репозитория:
* `install.ps1` — основной PowerShell скрипт для быстрого запуска одной строкой.
* `install.bat` — классический командный файл Windows (CMD) с автоматическим прописыванием путей.

## ✨ Преимущества решения
* **Безопасность:** Не ломает системные файлы и не требует вмешательства в реестр Windows.
* **Портативность:** Все установленные программы находятся в вашей пользовательской папке. Их можно легко перенести или удалить одной командой.
* **Автономия:** Идеально подходит для рабочих, учебных или гостевых ПК, где заблокирована установка стандартных инсталляторов.
